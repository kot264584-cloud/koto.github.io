> 课程：GAMES101 现代计算机图形学入门
> 讲师：闫令琪（Lingqi Yan），UC Santa Barbara
> 课程主页：<https://sites.cs.ucsb.edu/~lingqi/teaching/games101.html>

## 一、课程概况

GAMES101 是一门面向入门的现代计算机图形学课程，目标是建立图形学的完整知识框架，而不只是学习某个图形 API 或渲染引擎。

- 授课语言：中文授课，英文课件。
- 课时：共 22 节课，每节约 1 小时到 1 小时 15 分钟。
- 作业：8 次小作业，1 次大作业，全部为编程任务。
- 考试：无考试安排。
- 教材：Steve Marschner and Peter Shirley, *Fundamentals of Computer Graphics*。
- 前置要求：高等数学（微积分、线性代数）、算法、数据结构。
- 有帮助但非必须：信号处理、数值分析、大学物理（光学）。

课程明确不教 OpenGL、DirectX、Vulkan、Metal 等 API 的使用，不教 Maya、Blender 等建模软件，也不涉及计算机视觉、图像处理、深度学习和游戏引擎操作。课程讲的是这些工具背后的数学与物理原理。

## 二、课程主线

GAMES101 的核心内容可以分为四大部分：

1. 光栅化成像：如何把三维三角形最终显示到二维屏幕上。
2. 几何表示：如何表示曲线、曲面、网格和复杂形状。
3. 光的传播理论：如何模拟光线传播，生成真实感图像。
4. 动画与模拟：如何让物体和场景随时间运动。

一条贯穿课程的主线是：

```text
三维场景
  -> 模型、视图、投影变换
  -> 光栅化与着色
  -> 深度测试与抗锯齿
  -> 几何表示
  -> 光线追踪与全局光照
  -> 动画与物理模拟
```

## 三、分模块重点

### 1. 光栅化成像

光栅化是实时渲染的基础，重点不是调用 API，而是理解从三维顶点到像素颜色的全过程。

核心知识点：

- 向量、点积、叉积、矩阵和齐次坐标。
- 二维与三维变换：平移、旋转、缩放、剪切、仿射变换。
- 旋转矩阵、旋转合成和 Rodrigues 旋转公式。
- 模型变换、视图变换、投影变换组成的 MVP 变换流程。
- 相机约定：相机位于原点、看向 -z、上方为 +y。
- 正交投影与透视投影的区别和矩阵构造。
- 三角形光栅化：判断像素中心是否在三角形内。
- 重心坐标插值：用于颜色、法线、纹理坐标等属性的插值。
- 深度测试与 Z-buffer。
- 走样与抗锯齿：超采样、MSAA。
- Blinn-Phong 反射模型：环境光、漫反射、高光。
- 着色频率：平面着色、顶点着色、片元着色。
- 图形管线：顶点处理、光栅化、片元处理、输出合并。
- 纹理映射：UV 坐标、双线性插值、Mipmap。
- 凹凸贴图、法线贴图、位移贴图。

这一部分覆盖了实时渲染器最常用的工作流，也是理解游戏引擎和 UE 渲染管线的重要基础。

### 2. 几何表示

几何表示解决的是“如何描述和构造三维形状”的问题。

核心知识点：

- 隐式表示与显式表示。
- 点云、多边形网格。
- 贝塞尔曲线：Bernstein 基函数、控制点、De Casteljau 算法。
- 贝塞尔曲面和曲面细分。
- 网格处理：细分、简化、规则化。
- Catmull-Clark 细分等常用方法。
- 阴影图：从光源视角生成深度图，判断阴影。

几何部分是连接建模、动画、仿真和渲染的中间层，网格质量直接影响后续算法效率。

### 3. 光的传播与光线追踪

这一部分从几何光学进入物理渲染，解释真实感图像如何生成。

核心知识点：

- 光线生成、光线与场景求交。
- Moller-Trumbore 三角形求交算法。
- 加速结构：包围盒、AABB 求交、BVH。
- 辐射度量学：辐射通量、辐照度、辐射强度、辐射亮度。
- BRDF：描述材质如何反射光。
- 反射方程与渲染方程。
- 直接光照与全局光照。
- 蒙特卡洛积分与随机采样。
- 路径追踪算法及其递归采样。
- 材质与外观：漫反射、镜面反射、微表面模型。
- 高级光线传播方法：双向路径追踪、光子映射等。
- 相机与透镜、景深。
- 光场、颜色空间与视觉感知。

渲染方程是这一部分的中心概念。它把出射辐射亮度表示成自发辐射与入射光照经 BRDF 加权后的积分：

```text
L_o(p, w_o) = L_e(p, w_o) + ∫ f_r(p, w_i, w_o) L_i(p, w_i) cos(theta_i) dw_i
```

### 4. 动画与模拟

动画与模拟解决的是“场景如何随时间变化”的问题。

核心知识点：

- 关键帧动画与插值。
- 质点弹簧系统：弹簧力、阻尼、布料模拟。
- 粒子系统。
- 正向运动学与逆向运动学。
- 刚体模拟。
- 常微分方程数值求解：显式欧拉、隐式欧拉、Verlet。
- 数值稳定性与时间步长。
- 流体模拟的基本思想。

数值积分是动画模拟的关键。显式欧拉简单但可能不稳定，隐式欧拉更稳定，这是实现物理模拟时首先要理解的问题。

## 五、作业重点

8 次小作业对应课程的关键实现环节：

| 作业 | 主题 | 需要实现的重点 |
| --- | --- | --- |
| 作业 1 | 旋转与投影 | 模型矩阵、透视投影矩阵、绕任意轴旋转 |
| 作业 2 | 三角形与 Z-buffer | 三角形光栅化、深度缓冲、超采样抗锯齿 |
| 作业 3 | 管线与着色 | 属性插值、Blinn-Phong、纹理、凹凸/位移贴图 |
| 作业 4 | 贝塞尔曲线 | De Casteljau 算法 |
| 作业 5 | 光线与三角形求交 | 光线生成、Moller-Trumbore 算法 |
| 作业 6 | 加速结构 | 包围盒求交、BVH 构建与遍历 |
| 作业 7 | 路径追踪 | 蒙特卡洛路径追踪 |
| 作业 8 | 质点弹簧系统 | 绳索约束、显式/隐式欧拉、Verlet、阻尼 |

大作业通常需要综合运用课程知识，常见方向包括场景渲染、几何处理、物理模拟或真实感材质。

## 六、必须掌握的公式与概念清单

学习时可以对照这份清单检查自己是否真正掌握：

- 齐次坐标中点与向量的表示区别。
- 二维和三维旋转矩阵。
- Rodrigues 旋转公式。
- MVP 变换顺序：先模型，再视图，最后投影。
- 透视投影矩阵中远平面到近平面的“挤压”步骤。
- 重心坐标插值公式。
- Blinn-Phong 三项光照公式。
- 贝塞尔曲线 Bernstein 基函数与 De Casteljau 递推。
- Moller-Trumbore 求交公式。
- AABB 与光线求交。
- 渲染方程各项含义。
- 蒙特卡洛积分估计公式。
- 路径追踪的递归结构与终止策略。
- 质点弹簧系统的胡克定律与阻尼力。
- 显式欧拉、隐式欧拉、Verlet 的更新公式与稳定性差异。

## 七、学习建议

1. 第一遍先按 22 讲顺序理解知识框架，不要过早陷入某个 API 细节。
2. 对每一讲做两类笔记：一类是“概念和公式”，一类是“这个知识在渲染器中如何被使用”。
3. 作业不要只抄代码，重点完成矩阵、光栅化、求交、BVH、路径追踪和质点弹簧这些核心实现。
4. 学习光栅化时，可以对照 UE、Unity 的材质和渲染管线，理解它们背后的 MVP、着色和纹理概念。
5. 学习光线追踪时，先搞懂辐射度量学和渲染方程，再进入蒙特卡洛与路径追踪。
6. 动画部分重点理解数值积分的稳定性，而不是只记住代码。
